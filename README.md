# Car Parking Management System

## Overview
This Car Parking Management System is a software application designed to help you manage car parking areas efficiently. The system allows administrators to track car entries, exits, and parking statuses seamlessly.

## Features
- **Car Entry Management**: Add new cars to the parking system.
- **Car Invoice Generation**: Generate car entry invoices in PDF format.
- **Car Exit Management**: Update, delete, or mark cars as out.
- **Admin Access Only**: Only administrators can log in and manage the system.
- **Dashboard Overview**:
  - Total cars in parking
  - Total cars exited
  - Currently parked cars
- **Visual Data Representation**:
  - Car parking status displayed in a pie chart.
- **QR Code Verification**:
  - Users can scan a QR code to check if their car is parked.
  - Online verification available for parked cars.
